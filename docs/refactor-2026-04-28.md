# 重构记录

## 2026-04-28 重构：导入路径和常量管理标准化

### 背景

从 `next` 分支合并新功能时，发现项目中存在导入路径不一致的问题：
- 部分代码使用 `from backend.src.xxx` 前缀
- 部分代码直接使用 `from src.xxx`
- 路径常量分散在多个位置，存在重复定义

### 重构内容

#### 1. 导入路径统一
**问题**：项目根目录是 `backend/`，但后端执行目录也是 `backend/`，导致需要使用 `from backend.src.xxx` 或 `from src.xxx`

**解决**：以 `src/` 为根目录，统一使用 `from src.xxx` 格式

```
# 重构前
from backend.src.common.constant import path_constant
from backend.src.dao.yande_data import TagRepository

# 重构后
from src.common.constant import path_constant
from src.dao.yande_data import TagRepository
```

**影响的文件**：
- `src/__init__.py`
- `src/api/__init__.py`
- `src/api/v1/*.py` (config, download, favorites, gallery, tag_cache)
- `src/common/__init__.py`
- `src/common/constant.py`
- `src/common/settings.py`
- `src/dao/*.py` (database, favorite_dao, yande_data)
- `src/infrastructure/*.py` (download_queue, downloader, image_cache, yande_api)
- `src/middleware/*.py` (downloader, errors, frontend_static)
- `src/models/database/yande.py`
- `src/models/request/config.py`
- `src/models/response/*.py` (base_response, config)

#### 2. 路径常量统一使用 PathConstant

**问题**：存在两套路径常量定义
- `PathConstant` 类（使用 Pydantic frozen model）
- 散落的 `DOWNLOADS_DIR`, `PREVIEWS_DIR`, `ORIGINALS_DIR` 常量

**解决**：以 `PathConstant` 为唯一真值，删除重复的常量定义

```python
# PathConstant 定义
class PathConstant(ConstantModel):
    base_dir: Path = Path(__file__).parent.parent.parent
    download_dir: Path = base_dir / "downloads"
    previews_dir: Path = download_dir / "previews"
    originals_dir: Path = download_dir / "originals"
    ...

path_constant = PathConstant()
```

**使用方式**：
```python
# 重构前
from src.common import DOWNLOADS_DIR, PREVIEWS_DIR, ORIGINALS_DIR

# 重构后
from src.common import path_constant

# 使用
path_constant.download_dir
path_constant.previews_dir
path_constant.originals_dir
```

#### 3. ImageCache 重构

**问题**：`ImageCache` 类自己管理路径，没有使用 `path_constant`

**解决**：使用 `path_constant` 初始化，改用方法获取路径

```python
# 重构前
from src.common import DOWNLOADS_DIR, PREVIEWS_DIR, ORIGINALS_DIR

class ImageCache:
    DOWNLOADS_DIR = Path(DOWNLOADS_DIR)
    PREVIEWS_DIR = Path(PREVIEWS_DIR)
    ORIGINALS_DIR = Path(ORIGINALS_DIR)

# 重构后
from src.common import path_constant

class ImageCache:
    def __init__(self):
        self.DOWNLOADS_DIR = path_constant.download_dir
        self.PREVIEWS_DIR = path_constant.previews_dir
        self.ORIGINALS_DIR = path_constant.originals_dir
```

路径获取方法也改为返回 `Path` 对象：
```python
def get_preview_path(self, image_id: int, file_ext: str = "jpg") -> Path:
    return self.PREVIEWS_DIR / f"{image_id}.{file_ext}"
```

#### 4. download_queue.py 任务存储增强

**新增**：
- `TaskStore.TASK_FIELD_MAPPING`：外部字段名到内部字段名的映射
- `TaskStore.TASK_DEFAULTS`：内部任务的默认值配置

```python
class TaskStore:
    # 任务字段映射配置
    TASK_FIELD_MAPPING = {
        "image_id": "image_id",
        "file_url": "file_url",
        ...
    }

    # 内部任务默认值
    TASK_DEFAULTS = {
        "status": TaskStatus.PENDING,
        "progress": 0.0,
        ...
    }
```
