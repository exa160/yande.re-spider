# 需求规格文档

## 文档信息
- **项目名称**: yande.re-spider-next
- **功能名称**: 高级查询功能与多端界面优化
- **版本**: v1.0
- **创建日期**: 2025-03-26
- **最后更新**: 2025-03-26

## 1. 概述

### 1.1 项目背景
yande.re-spider-next 是一个基于 yande.re 网站 API 的图片批量下载工具，当前已实现基础的标签搜索、分页下载、多线程下载等功能。项目使用 Python 开发，包含基础的 Tkinter GUI 界面。为了提升用户体验和功能完整性，需要补全高级查询功能并开发现代化的多端界面。

### 1.2 功能范围
本次优化包含以下核心功能：
1. **高级查询功能补全**：支持多条件组合查询、评分过滤、分辨率过滤、文件类型过滤等高级搜索功能，并提供统一查询接口供界面展示和下载功能共同使用
2. **多端界面开发**：开发支持 Web、桌面、移动端的现代化界面，界面集成高级查询功能
3. **图库流式显示**：实现图片瀑布流展示，支持预览和详情查看，图库展示基于统一查询接口
4. **下载器功能集成**：在界面中集成下载管理、进度显示、任务队列管理，下载任务创建基于统一查询接口，支持重复图片识别与跳过，下载成功后自动记录图片信息到数据库
5. **配置管理界面**：提供可视化的配置修改功能

**核心设计原则**：
- 界面展示模块和下载功能模块使用相同的高级查询接口，确保查询字段、查询逻辑和查询结果的一致性
- 下载器继承并增强现有的重复图片识别功能，确保不重复下载已存在的图片
- 下载成功后将API获取的完整图片信息持久化到数据库，保证数据完整性，并可将该数据用于浏览界面的后续查询

### 1.3 排除范围
- 不涉及爬虫核心算法的修改
- 不涉及数据库结构的重大调整
- 不涉及第三方 API 接口的扩展

## 2. 功能需求

### 2.1 高级查询功能

#### 需求 2.1.1: 统一查询接口设计
**优先级**: P0
**描述**: 系统应当提供统一的高级查询接口，该接口同时服务于界面展示和下载功能，确保查询字段和查询逻辑的一致性。

**验收标准**:
- [ ] 定义统一的查询参数模型，包含所有可查询字段
- [ ] 界面展示模块和下载模块使用相同的查询接口
- [ ] 查询字段包括：标签、评分、分辨率、文件类型、评级、创建时间、作者等
- [ ] 查询接口支持参数验证和错误提示
- [ ] 查询接口文档完整，包含所有字段的说明和示例

#### 需求 2.1.2: 多条件组合查询
**优先级**: P0
**描述**: 系统应当支持用户通过多个条件组合进行图片查询，包括标签、评分、分辨率、文件类型等条件的逻辑组合（AND、OR、NOT）。

**验收标准**:
- [ ] 用户可以同时指定多个标签进行查询
- [ ] 用户可以选择标签之间的逻辑关系（AND、OR、NOT）
- [ ] 用户可以指定评分范围进行过滤
- [ ] 用户可以指定分辨率范围进行过滤
- [ ] 用户可以指定文件类型（jpg、png、gif等）进行过滤
- [ ] 查询结果应当符合所有指定条件的组合逻辑
- [ ] 界面查询和下载查询使用相同的多条件组合逻辑

#### 需求 2.1.3: 评分过滤查询
**优先级**: P1
**描述**: 系统应当支持根据图片评分进行过滤查询，用户可以指定最低评分和最高评分范围。

**验收标准**:
- [ ] 用户可以设置最低评分阈值
- [ ] 用户可以设置最高评分阈值
- [ ] 查询结果中所有图片的评分都在指定范围内
- [ ] 评分过滤可以与其他查询条件组合使用
- [ ] 界面和下载功能使用相同的评分过滤逻辑

#### 需求 2.1.4: 分辨率过滤查询
**优先级**: P1
**描述**: 系统应当支持根据图片分辨率进行过滤查询，用户可以指定最小和最大宽度、高度范围。

**验收标准**:
- [ ] 用户可以设置最小宽度阈值
- [ ] 用户可以设置最小高度阈值
- [ ] 用户可以设置最大宽度阈值
- [ ] 用户可以设置最大高度阈值

#### 需求 2.1.5: 文件类型过滤查询
**优先级**: P1
**描述**: 系统应当支持根据文件类型进行过滤查询，用户可以选择一种或多种文件类型。

**验收标准**:
- [ ] 用户可以选择单个文件类型进行过滤

- [ ] 支持的文件类型包括：jpg、png、gif、webp
