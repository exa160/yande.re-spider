## 2026-05-02 重构：批量下载、down_flag、YandeApi 重试机制等修复

### 1. 批量下载功能优化

**问题**：Gallery.vue 批量下载按钮在 for 循环中逐个调用 `/download/task`，网络开销大

**解决**：改用 `/download/task/batch` 批量接口

```javascript
// 修复前：循环单任务接口
for (const image of selectedImages.value) {
  await api.post('/download/task', { ... })
}

// 修复后：一次性批量创建
await api.post('/download/task/batch', tasks)
```

**提交**：`cea6b36`

### 4. ImageCache 重试机制

**问题**：`download_preview()` 和 `save_original()` 无重试

**解决**：添加 3 次重试 + `raise_for_status()`

```python
for i in range(config.yande_api.retry):
    try:
        resp = requests.get(..., timeout=config.yande_api.timeout)
        if resp.status_code == 200:
            ...
    except Exception as e:
        if i == config.yande_api.retry - 1:
            raise
```

**提交**：`cea6b36`

### 5. Rating 枚举递归错误

**问题**：`Rating.value` 属性覆盖 Python Enum 内置属性，导致无限递归

```python
# 修复前（错误）
@property
def value(self):
    return self.value[0]  # 递归调用自己！

# 修复后（正确）
@property
def code(self):
    return self.value[0]
```

**提交**：`cea6b36`
